# RTI-Ease

An AI-powered CivicTech platform designed to democratize the Right to Information (RTI) process in India by helping citizens draft legally precise, rejection-proof applications.

## Core Features
* **Plain Language to Legal Draft:** Translates everyday grievances into structured, formal RTI templates.
* **Smart Department Routing:** Identifies and maps the issue to the correct Public Information Officer (PIO).
* **One-Click Export:** Generates ready-to-print PDFs for submission.

## Tech Stack
* **Frontend:** React (Next.js) / Tailwind CSS
* **Backend:** Python (FastAPI)
* **AI Engine:** OpenAI API (GPT-4o-mini)
* **Database:** Supabase (PostgreSQL)

## Quick Start
1. Clone the repo: `git clone <repo-url>`
2. Install frontend dependencies: `npm install`
3. Install backend dependencies: `pip install -r requirements.txt`
4. Run the development servers: `npm run dev` & `uvicorn main:app --reload`
